# Architecture Decision Records

This directory records major, irreversible architecture decisions for PolyGlid.
Each ADR is a Markdown file named `NNNx-summary-of-decision.md`, where `NNN` is a
zero-padded number assigned sequentially.

ADRs are written once a decision is **accepted** and implemented. Each follows
Michael Nygard's [MADR](https://adr.github.io/) format.
