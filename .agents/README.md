# PolyGlid Agent Workspace

`.agents/shared/` is the source of truth for AI-assisted development.

- Start with `shared/agent-startup.md`.
- Use `shared/memory/` for stable facts and decisions.
- Load `shared/scopes/` according to the code being changed.
- Load individual files from `shared/rules/` only when relevant.
- Use `shared/context/architecture.md` when a task crosses layers.

This knowledge base describes the active `main` branch. The reference branches
are research sources, not alternative implementation roots.
