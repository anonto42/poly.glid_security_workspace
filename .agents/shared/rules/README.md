# Rule Index

Load only what matches the task:

- Any Rust implementation: `rust.md`
- Dioxus UI or state: `desktop-ui.md`
- Filesystem deletion, plugins, permissions, signatures, runtime, or reports:
  `security-boundaries.md`
- Tests or verification: `testing.md`

Rules record non-obvious constraints and repeated traps. Architecture maps and
temporary task notes do not belong here.
